Veterinaria Aurora

DESCRIPCIÓN
Veterinaria Aurora es un proyecto de desarrollo web creado para presentar los servicios de una clínica veterinaria y brindar información útil a las personas que desean cuidar la salud y el bienestar de sus mascotas.

OBJETIVO
Desarrollar un sitio web sencillo, atractivo y fácil de utilizar, donde los visitantes puedan conocer la veterinaria, consultar sus servicios y encontrar información de contacto.

TECNOLOGÍAS UTILIZADAS
- HTML5: estructura de las páginas.
- CSS3: diseño y estilos visuales.
- JavaScript: funciones interactivas, si se utiliza en el proyecto.

ESTRUCTURA DEL PROYECTO
- `index.html`: página principal.
- `servicios.html`: información sobre los servicios.
- `contact.html`: información de contacto.
- `style.css`: estilos y diseño del sitio web.
- `script.js`: scripts y backend de toda la página web.
  

COMO VISUALIZAR EL PROYECTO
1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Abre el archivo `index.html` en un navegador web.
4. Utiliza el menú de navegación para visitar las demás páginas.
